# Glossary: Applications Tracker

Używaj tych słów w kodzie, testach, commitach i rozmowach. Gdy nazwa w kodzie różni się od pojęcia, w nowym kodzie wygrywa pojęcie. Zmiana nazw w starym kodzie to osobna decyzja.

| term                          | means                                                                                                                      | name in code                                                        | don't call it                                                                     |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| application                   | jeden proces rekrutacyjny kandydata u jednej firmy na jedno stanowisko                                                     | `applications`, `Application`                                       | offer (to status), job, posting                                                   |
| company / position            | dwa jedyne wymagane pola aplikacji                                                                                         | `company`, `position`                                               | —                                                                                 |
| salary range                  | widełki podane w ogłoszeniu                                                                                                | `salary_range`                                                      | rate, stawka                                                                      |
| quoted rate                   | stawka, którą kandydat sam podał firmie                                                                                    | `quoted_rate`                                                       | salary, widełki; w UI jedna etykieta zamiast „Moja podana stawka” i „Moja stawka” |
| HR contact                    | osoba rekrutera: imię i nazwisko oraz telefon                                                                              | `hr_contact_name`, `hr_contact_phone`                               | status „Kontakt HR” (to inny byt)                                                 |
| posting                       | ogłoszenie, do którego prowadzi link                                                                                       | `posting_url`                                                       | offer                                                                             |
| status                        | etap aplikacji: Sent, HR contact, Interviews, Offer (aktywne), Accepted, Rejected, Withdrawn (terminalne)                  | `application_status`, `APPLICATION_STATUSES`                        | stage (to tylko ranga do sortowania)                                              |
| active status                 | Sent, HR contact, Interviews, Offer                                                                                        | `ACTIVE_STATUSES`                                                   | open                                                                              |
| terminal status               | Accepted, Rejected, Withdrawn; wyjście z niego to revert                                                                   | `TERMINAL_STATUSES`                                                 | closed (closed nie obejmuje Accepted)                                             |
| closed status                 | tylko Rejected i Withdrawn: dół listy, przekreślone                                                                        | `CLOSED_STATUSES`                                                   | terminal                                                                          |
| forward move                  | zmiana na późniejszy etap, także z pominięciem etapów i prosto do Accepted                                                 | `kind: "forward"`                                                   | upgrade, promote                                                                  |
| revert                        | wyjście ze statusu terminalnego do dowolnego innego, tylko po potwierdzeniu, zapisane w historii                           | `kind: "revert"`, `is_revert`                                       | undo, rollback, reopen                                                            |
| withdraw (remove application) | „usunięcie” aplikacji = status Withdrawn; nic nie znika                                                                    | status `withdrawn`                                                  | delete                                                                            |
| note                          | datowany wpis przy aplikacji, typu comment albo phone call                                                                 | `notes`, `Note`                                                     | comment (to typ), log                                                             |
| removed note                  | notatka oznaczona jako usunięta; zostaje na osi czasu, przekreślona                                                        | `deleted_at`, `removeNote`                                          | deleted, purge                                                                    |
| note revision                 | poprzednia wersja edytowanej notatki                                                                                       | `note_revisions`                                                    | history                                                                           |
| change log                    | historia aplikacji: zmiany pól (także CV), zmiany statusu i rewizje notatek                                                | `field_changes`, `status_changes`, `note_revisions`, `mergeHistory` | audit, events                                                                     |
| rate note                     | uzasadnienie zmiany stawki, zapisywane jako notatka typu comment                                                           | `rate_change_note`                                                  | —                                                                                 |
| most recent activity          | moment zapisu notatki albo zmiany statusu (edycje pól, notatek i CV się nie liczą)                                         | `last_activity_at`                                                  | updated_at                                                                        |
| ordering                      | kolejność listy: Accepted, Offer, Interviews, HR contact, Sent, potem Rejected i Withdrawn; w etapie najświeższa aktywność | `STAGE_RANK`, sort w `status.ts`                                    | priority, score                                                                   |
| most recent agreement         | to, co pokazuje podsumowanie na rozmowę; definicja otwarta (Q-06)                                                          | _missing in code_ (najbliżej: `latestActiveNote`)                   | last note                                                                         |
| waiting for a response        | aplikacje, które czekają na ruch firmy; definicja otwarta (Q-04)                                                           | _missing in code_                                                   | —                                                                                 |
| call summary                  | to, co widać pierwsze w szczegółach: widełki, stawka, status, ostatnie ustalenie                                           | `data-testid="call-summary"`                                        | header                                                                            |
| search                        | szukanie po firmie, stanowisku, nazwisku i telefonie HR, niezależnie od formatu telefonu                                   | `matchesQuery`, `filterApplications`                                | —                                                                                 |
| status filter                 | zawężenie listy do jednego lub kilku statusów, razem z wyszukiwaniem                                                       | `parseStatusFilter`, `?status=`                                     | —                                                                                 |
| CV                            | plik PDF lub DOCX do 5 MB w bibliotece właściciela, przechowywany raz na treść                                             | `cv_files`, `CvFile`                                                | resume, attachment                                                                |
| CV library                    | wszystkie CV właściciela z listą aplikacji, do których są podpięte                                                         | `/cv`, `listCvFiles`                                                | —                                                                                 |
| attach CV                     | wskazanie jednego CV z biblioteki dla aplikacji; zapisywane w historii jako pole `cv`                                      | `set_application_cv`, `cv_file_id`                                  | upload (to dodanie do biblioteki)                                                 |
| owner                         | jedyny użytkownik konta, tworzony poza aplikacją                                                                           | `user_id`, `auth.uid()`                                             | user signup                                                                       |
| purge demo data               | twarde usunięcie danych `[TEST]` przez skrypt operatora; wyjątek od „nothing is deleted” (Q-01)                            | `demo-data --reset`                                                 | remove, withdraw                                                                  |
